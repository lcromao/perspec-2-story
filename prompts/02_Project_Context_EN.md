# Shared evaluation context

## Objective

Complete a comparative expert evaluation of two specifications of Data and Model Stories for an ML-enabled system, using the questionnaire in the attached pair context.

## Questionnaire conventions

- The attached pair context contains one form: the project summary, the Team X and Team Y versions of seven stories, and the original questions with their options.
- Team X and Team Y are anonymous labels that apply only to this form.
- Answer options: `Team X's version`; `Team Y's version`; `No preference (both are equivalent)`.
- Each form has 28 preference questions (`.a`) and 28 corresponding comment questions (`.b`). Comment questions are optional in the original form; in this run, write an explanation for every one.
- Use the exact story-level definitions and question IDs from the pair context. No numerical scale or absolute binary label is requested.
- The project summary defines the task scope. All targets and resource limits in it are proposed pilot decisions, not achieved results.
- Output language: English.

## Question identifiers

| Story number | Story type | Preference questions | Comment questions |
|---|---|---|---|
| 1 | Data Collection | 1.1.a through 1.4.a | 1.1.b through 1.4.b |
| 2 | Data Pre-processing | 2.1.a through 2.4.a | 2.1.b through 2.4.b |
| 3 | Data Management | 3.1.a through 3.4.a | 3.1.b through 3.4.b |
| 4 | Model Feature Preprocessing | 4.1.a through 4.4.a | 4.1.b through 4.4.b |
| 5 | Model Training & Evaluation | 5.1.a through 5.4.a | 5.1.b through 5.4.b |
| 6 | Model Deployment | 6.1.a through 6.4.a | 6.1.b through 6.4.b |
| 7 | Model Integration | 7.1.a through 7.4.a | 7.1.b through 7.4.b |

Within every story, characteristic 1 is Completeness, 2 is Clarity, 3 is Correctness, and 4 is Consistency.
